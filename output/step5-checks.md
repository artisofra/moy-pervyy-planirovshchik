## Объём, скорость и ограничения

Полный инженерный пример: **10 объектов, 100 этапов, 500 работ, 2500 ресурсов, 5000 платежей и 5000 событий истории**. JSON — 4 501 964 байта. Через настоящий файловый ввод выполнены проверка, сравнение и импорт; полное содержимое базы сверено.

В итоговом desktop-прогоне загрузка до готового сравнения UI — **2814 мс**. Пять повторов: финансовый фильтр/пересчёт **13,7–16,4 мс**, Гант **1,9–4,3 мс**, история **0,7–1,3 мс**, проверка входящего файла **698,2–807,8 мс**, сравнение **778,1–889 мс**. Файл с точными пятью измерениями и параметрами устройства — `step5-performance.json`. Навигационный HTML в этом наборе подан без антивирусной модификации, как объяснено ниже. Цели 1/5 секунд подтверждены на указанном компьютере; производительность современного телефона не заявляется проверенной.

Проверены включительные границы всех защитных лимитов и отказ при +1; реальные 100/101 объектов, JSON больше 20 МиБ, разрешённое уменьшение старого превышения 102→101 и запрет неизменного/возросшего превышения. Отказ не меняет базу и сохраняет ввод. Проверка при сохранении берёт прежнюю запись внутри той же транзакции; stale не перезаписывает данные. История/архив автоматически не сокращаются.

На реальном UI проверены 250 работ/ресурсов/общих расходов и 101 этап: порции доступны до конца, поиск находит скрытую запись. История — 100/200 из 5000, финансовые детали — 100 из 5000 с полным итогом, Гант — первые 150 с полной печатью выбранных строк. Все шесть экранов проверены на 360/768/1440 px без общей горизонтальной прокрутки; мобильный и desktop-снимки просмотрены.

## Офлайн и безопасность

Кеш содержит только 21 ресурс интерфейса; планы в IndexedDB. Пройдены запуск в подпапке, manifest/иконки, полная перезагрузка без сети, реальный download/upload, очистка только кеша, повтор подготовки, неудачная первая/следующая загрузка, несовпадение хешей, отказ замены рабочей версии, сохранность постороннего кеша, обновление с формой/настройками в двух вкладках, отсутствие service worker, file:// и полный перезапуск Chrome.

Обновление явно применяется после завершения ввода; изменение подписи не теряет параллельные правки объектов. Первичная ошибка IndexedDB не изображается успешной подготовкой. Установка вызывается только пользовательским действием; тест обработчика не заменяет реальную ОС-установку.

Исходники и комплект не содержат внешних API/скриптов/телеметрии, исполнения HTML из строк, eval/Function и финансовых console.log. В изолированной проверке исходного HTML нет попыток внешних запросов или передачи тела: только локальные GET. CSP допускает локальные модули, manifest, service worker и работающую печать. Опасный импорт, UTF-8, неизвестные поля, коллизии ID и отказ записи откатываются целиком.

**Особенность среды:** установленный антивирус Kaspersky добавляет свой внешний script в браузерный HTML-ответ до CSP. Это подтверждено сравнением файла на диске, тела ответа и DOM; в исходниках приложения вставки нет. В итоговом сетевом наборе навигационный index подан из неизменённой поставки через Playwright interception, внешние попытки блокируются и проверяются как ошибка. Обычные UI/офлайн-наборы проходят без этой подмены. Настройки антивируса не менялись. Детали без служебных query-идентификаторов — `step5-network-environment.json`. Утверждения о приватности относятся к коду приложения; поведение установленного на устройстве ПО им не контролируется.
