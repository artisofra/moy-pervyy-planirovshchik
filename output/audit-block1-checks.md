# Исправления аудита D01–D04 — 24.10.2026

Первый согласованный блок завершён. D05–D09 не включались в этот блок и остаются открытыми. Требования ТЗ, модель денег и формат обмена JSON не менялись; реальные устройства и публикация не объявлены проверенными/выполненными.

## Что изменено

- **D01:** единые чистые функции порядка: этапы/работы по sortOrder и ID, ресурсы/платежи по фактическому времени создания и ID. Разная точность ISO UTC не меняет хронологию. Обычная правка сохраняет место работы; перенос/создание идёт после последнего номера, включая пропуски после удаления. Просмотр/сортировка не меняют исходные массивы, редакции и историю.
- **D02:** работа сворачивается кнопкой, доступной с клавиатуры, с aria-expanded/aria-controls. Название, статус, сроки и сумма остаются видимыми. Поиск раскрывает подходящую работу, чтобы найденный ресурс можно было открыть. Состояние хранится только в текущем представлении.
- **D03:** редактор платежей выделен в `payment-editor.js`. У поля есть уникальная связь с платежом, подпись и сообщение ошибки. Ошибка переводит к нужной порции и полю; ошибочное имя платежа не выделяет имя ресурса. Неверные строки сохраняются до исправления/отмены. Все платежи проверяются до транзакции.
- **D04:** редактор показывает по 100 платежей; предыдущая/следующая порции сохраняют ввод, включая промежуточные неверные строки. Сумма/сохранение/валидация охватывают весь список. Аварийная копия после отказа содержит `unsavedPayments` всех порций, а не только видимых DOM-полей. Добавление показывает новую строку. Архивный ресурс листается без редактирования. В истории порционируются изменения внутри события, в архиве — подходящие записи.
